## 任务优先级说明

| 优先级 | 定义 | 说明 |
|--------|------|------|
| **P0** | 核心 MVP | 缺少则无法验证核心价值，必须先做 |
| **P1** | v1.0 交付 | 对用户体验有重大影响，应该有 |
| **P2** | v1.1 迭代 | 有则更好，可排到后续版本 |

## 快速启动建议

如果团队人力有限，建议 **分两条线并行**：

**线 A（后端）**：P0-1 → P0-2 → P0-3 → P0-4 → P0-5 → P0-6（M1）
**线 B（前端）**：P1-1 → P1-4（M2 可以提前接入 API）

或者 **按功能模块开发**：

1. 先实现 P0-3（知识库）+ P0-5（衣物管理）→ 有数据可测试
2. 再实现 P0-2（OutfitAdvisor）+ P0-4（Supervisor）→ Agent 核心
3. 最后 P0-6（前端集成）→ 端到端验证
